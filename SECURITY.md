# Security Policy

## 🛡 Supported Versions

We actively provide security updates for the following versions of MarketFlow AI:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability within MarketFlow AI, please do not disclose it publicly in an open issue.

Instead, please send an email directly to the maintainers or report it privately through GitHub's Private Vulnerability Reporting mechanism.

Please include:
- A description of the vulnerability.
- Steps or proof-of-concept to reproduce the vulnerability.
- Impact assessment.

We will acknowledge receipt within 48 hours and work on a prompt remediation.
